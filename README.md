# Backend Loja de Crochê

API desenvolvida em Node.js com Express para autenticação de login da loja de crochê.

## Tecnologias
- Node.js
- Express
- CORS
- Dotenv
- Nodemon
- Docker

## Como rodar localmente
1. Instale as dependências:
   npm install

2. Crie o arquivo `.env`:
   PORT=3000

3. Inicie o projeto:
   npm run dev

## Endpoint
- POST /api/auth/login
